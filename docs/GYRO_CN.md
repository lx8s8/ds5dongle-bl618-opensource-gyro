# BL616 / BL618 固件陀螺仪映射 G2

体感计算在接收器固件中运行，网页负责设置和观察，关闭网页后继续生效。默认四套配置均关闭体感。G2 增加四套独立体感配置、手柄快捷动作、扳机滞回、L2 瞄准倍率、板载灯提示和性能统计。

主机模拟、协议和网页测试用于软件验证；真实接收器、手柄与游戏的联调仍待完成。下一次调试可按 [真机验收清单](HARDWARE_TEST_CN.md) 逐项记录。后续功能状态见 [新增与优化清单](ROADMAP_CN.md)，完整报告布局见 [扩展协议](GYRO_PROTOCOL.md)。

## 打开网页与保存设置

在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory web
```

桌面 Chrome / Edge 打开 `http://127.0.0.1:8765/`，连接 USB 接收器。页面分为“接收器配置 / 手柄测试 / 固件更新”，不依赖外部脚本。新网页需要 G2 固件提供四种体感扩展报告，不能连接原装直连手柄或旧 G1 固件。

| 操作 | 作用 |
| --- | --- |
| 编辑配置 1–4 | 在四份表单草稿之间切换；不自动切换当前生效配置 |
| 应用 | 将当前编辑档和全局切档/快捷键设置应用到 RAM，立即生效 |
| 保存到设备 | 应用全部四档草稿和全局设置，再保存到 Flash，断电保留 |
| 切换到此配置 | 在“手动 / 快捷键”模式切到当前编辑档；只改变选择，不应用尚未提交的参数 |
| 恢复默认 | 当前编辑档在 RAM 恢复为默认关闭，其他档不变；保存后才永久生效 |
| 重新读取配置 | 从接收器读取四档和全局设置，覆盖网页草稿 |
| 导入 / 导出配置 | JSON 包含四档和全局设置；导入只填表单，需应用或保存 |

网页导入旧 v1 JSON 时，将原设置迁移到配置 1，保留原来的启用档位限制，其余三档默认关闭。固件首次加载旧 `gyro_cfg_v1` 也按此规则迁移；点击“保存到设备”后写入 G2 格式。

## Edge：Fn 直接切换独立体感配置

例如让 Fn + △ 普通游玩、Fn + □ 启用鼠标瞄准：

1. 编辑配置 1，输出方式选“关闭体感”。
2. 编辑配置 2，选“鼠标”，点击“按住 L2”或“长按 L2 · 300ms”预设，调好灵敏度。
3. 切档方式选“Edge Fn”，把 Fn + △ 绑定配置 1、Fn + □ 绑定配置 2，其余设为“关闭”或所需配置。
4. 点击“保存到设备”。日常直接操作手柄 Fn 组合键切档。

每个 Fn 档均可绑定配置 1–4 或关闭，各档可使用不同输出、灵敏度、启用按键和曲线。接收器读取手柄实际上报的当前原生档位，未知档位会关闭这层映射。切档清空旧的鼠标积压、滤波和临时开关状态。

手柄原生按键布局、摇杆曲线等仍由 PS5 / PlayStation Accessories 管理；网页只保存接收器体感设置。接收器原有按键 remap 仍为两套，四套指独立体感参数。

## 普通 DualSense：快捷键、两档绑定与网页开关

**四档快捷切换：** 切档方式选“手动 / 快捷键”，在“快捷键”中设置“下一配置 / 上一配置 / 指定配置”。例如 `Create + R3` 长按 300ms 切下一档，并选择“组合成立时屏蔽”。不需要常开网页。

**跟随接收器两档：** 切档方式选“接收器映射档”，把档 1 / 2 分别绑定所需体感配置或关闭。`Create + ← / →` 切接收器档 1 / 2，原有按键 remap 一起切换。

**仅切体感开关：** 全局快捷动作“体感开关”会临时暂停/恢复当前体感映射；它仍受本档输出、L2 等启用条件限制。也可以在本档启用方式中选择“按一次切换开关”。两种临时开关不要重复绑定同一组合。

**网页操作：** 输出方式选“关闭体感”后应用，或者手动切到预先设为关闭的配置。保存后保留关闭策略。临时暂停、toggle 和精瞄状态在重连或超过 100ms 无输入后复位，不作为持久配置保存。

## 快捷动作与按键

提供四个全局快捷动作，每个动作的所选按键必须同时成立。

| 动作 | 使用范围 |
| --- | --- |
| 下一配置 / 上一配置 / 指定配置 | 仅“手动 / 快捷键”模式切换四套体感配置 |
| 体感开关 | 临时暂停/恢复当前映射 |
| 静止校准 | 开始一次手动零偏校准 |
| 按住精瞄 | 按住时使用 0.01–1 倍临时灵敏度，松开恢复；多个精瞄同时成立取最小值 |

触发方式为按下、长按 1–3000ms、双击；双击的单次按下和间隔窗口均为 300ms。精瞄仅支持按下或长按。持续按住不会重复切档；重连和长间隔后需释放再按。完全相同的组合不能重复绑定，部分重叠的组合仍应自行避免同时触发。

原始按键可选“保留 / 组合成立时屏蔽 / 始终屏蔽所选按键”。组合成立时屏蔽从整组按下起生效，不等待长按或双击完成；组合键逐个按下时，较早按下的单键可能已到达游戏。自定义快捷键先于内建 Create 组合处理，整组成立并选择屏蔽时可避免同时触发内建动作。

体感启用源支持普通按键、方向键、触摸板点击、触摸接触、Edge 左右 Fn 与 L4/R4。普通启用条件可选任一个或全部；扳机条件与按键条件之间为 AND。每档“屏蔽原始按键”会始终屏蔽该档选中的启用源，不只在映射激活时屏蔽。折叠项“启用档位限制”是额外限制，通常保持“不限制档位”，全局切档绑定即可满足日常需要。

Edge 背键的独立绑定需要手柄上报物理位。本次真机在原生默认档能读到独立 L4/R4；原生档 3 已把背键映射为 L3 / × 时，只收到映射后的普通按键，没有独立背键位。需要独立绑定时，使用未给该背键分配普通按键的原生配置，并用按键学习确认；接收器无法凭同一个普通按键输出区分其来源。详见 [真机记录](HARDWARE_RESULT_2026-11-14_CN.md#g21t-本地构建验收) 与 [参考项目的背键说明](https://github.com/artzox/DS5Dongle-Studio/blob/master/README.md#dualsense-edge-buttons-new-in-1290)。普通 DualSense 没有独立背键，第三方背键能否单独识别同样取决于是否有独立上报位。

## 映射参数

| 设置 | 含义 |
| --- | --- |
| 输出方式 | 关闭 / HID 相对鼠标 / USB DualSense 右摇杆 |
| 启用方式 | 始终、按住、按一次切换、按住暂停；延时 0–3000ms |
| 扳机阈值 / 释放阈值 | 上升达到启用阈值后成立，下降到释放阈值以下才解除；例如 70 / 55，减少临界抖动；默认 64 / 64 保持旧行为 |
| L2 瞄准倍率 | L2 按下时乘 0.01–4 倍，松开恢复；使用同组启用/释放阈值，独立于启用源；默认 1 倍 |
| 水平轴 | 本地 Yaw（Y）、本地 Roll（Z）或 **玩家空间 · 重力防串轴**（结合三轴加速度计实时估计重力方向，消除斜握俯仰串轴），垂直为 Pitch（X） |
| X/Y 灵敏度 | 各轴 0.01–100 倍，可反转；与 ADS 和精瞄倍率相乘 |
| 鼠标基准 | 0.01–100 counts/°，再乘灵敏度；游戏设置决定最终视角 |
| 微动死区 | 0–10°/s，二维速度减去阈值后平滑收缩到零；支持勾选**自动静止温漂校正**（1 秒静止窗口慢速学习温漂零偏） |
| 平滑 | 低通时间常数 0–100ms，0 禁用；支持勾选**自适应速度分段滤波**（微瞄 1.8x 强抑抖、≥45°/s 快速甩枪零延迟直通） |
| 加速 | 手部速度在起止阈值间插值，从 1 倍升至最大倍率 |
| 开火下压偏置（离线 / 单机测试） | 通用选项：按住 R2 且体感激活时，向下叠加固定速度 0–63.5°/s，可设 0–3150ms 渐入；使用本档扳机阈值/释放阈值，随垂直灵敏度和 L2 倍率缩放，垂直反转不改变方向。固件和网页都不含任何武器参数，需自行按游戏手感调；联机竞技游戏通常禁止此类自动压枪，请勿在其中使用 |
| 游戏满杆转速 | 满杆转一圈耗时 T 秒时填写 360/T °/s（网页提供右摇杆校准向导与常见游戏预设模板一键计算） |
| 游戏死区补偿 / 曲线 | 对二维目标速度幅度做径向死区和幂曲线反变换，保持向量方向；游戏无死区时应设为 0 |
| 物理右摇杆 | 与体感相加，或只在体感激活时替代 |

鼠标按传感器时间差积分并保留小数残差。USB 忙时保留待发位移，单包每轴 ±127 counts，积压每轴最多 ±2048 counts；松手、关闭、离开允许档位时清空。触摸板与按键鼠标共用发送路径。

右杆仍为 DualSense HID，不是 XInput，受游戏满杆速度、8bit 分辨率、曲线和混合输入支持限制。原始 IMU 数据仍透传，主机映射软件也使用体感时应避免重复映射。

## 校准与状态灯

工厂 Feature 0x05 数据验证后用于原始值到 °/s 换算；不可用时采用标称 `16 raw counts/(°/s)`，网页显示“标称值”。Linux 归一化后的 1024 不是这里原始 HID 的换算因子。

点击“静止校准”，放稳手柄连续 2 秒且至少 100 个样本。要求三轴角速度不超过 3°/s、窗口波动不超过 0.8°/s、加速度约 0.9–1.1g；运动时重新积累静止窗口。30 秒未成功会显示“校准超时”，可重新开始，原有零偏继续保留。清除校准只移除手动零偏，保留工厂标定。

校准期间暂停体感映射。不自动学习慢速动作，避免把跟枪学成零偏。工厂数据和手动零偏只绑定当前连接，断连换手柄后重新获取/校准，不写入四档配置。传感器 timestamp 约 1/3µs，差值按无符号数处理回绕；传感器或接收间隔超过 50ms 重建历史，100ms 无样本清空流状态，首样本不积分鼠标。

开启“状态灯提示”后，用接收器板载灯短闪反馈：切到配置 1–4 闪对应次数，暂停闪 1 次、恢复闪 2 次，校准开始闪 1 次、成功闪 3 次、超时闪 4 次。提示完成恢复此前常亮/熄灭状态；电量警告、断连、扫描与 LED 锁优先。此项不修改手柄灯效或触觉，不提供震动提示。

## 调试与保存可靠性

“手柄测试”显示原始按键、IMU、校正角速度、实际 USB 右杆、当前档位和校准状态，可导出最多 600 个网页观测点的 CSV。状态约 10Hz、性能统计约 1Hz 刷新，均不代表完整输入录制。

性能统计记录接收器处理报告的间隔 min/avg/max 与五档分布、体感处理耗时、超过 50ms 的间隔、鼠标 USB busy、命令队列峰值/丢弃及 Flash 保存耗时/结果，可导出 JSON。间隔是在接收器任务中观察到的，不等于无线丢包率或端到端延迟；断连时间也可能计入长间隔，比较前应重新启动接收器并采用相同采样时段。直方图每桶 u16 饱和后停止增长，其余计数 u32 饱和。

四档与全局设置使用带代数和 CRC32 的 A/B 记录，启动选择最新有效副本，损坏时回退另一份；两份无效时尝试旧配置。保存相同内容去重。手柄/网页手动切档以及原 remap 两档均先在 RAM 生效，最后一次切换约 1 秒后合并保存，失败约 5 秒后重试；切完立即断电可能仍恢复上次保存档位。手动选择另存带代数和 CRC 的小记录；保存整套配置会合入当前手动选择。

配置、remap 和体感写命令均在 USB 中断入队，由 usb_task 验证和执行，GET 返回已发布快照。旧 remap 表格式不改，A/B 校验恢复针对新增体感配置库。队列满会丢弃请求并计数，网页等待匹配回执后才显示成功，未收到则超时。失败不会伪报保存成功；A/B 机制仍须实机断电试验确认 Flash 后端行为。

## 软件验证

```sh
make -C tests check
make -C tests sanitize
node --check web/app.js
python3 -m unittest discover -s tests -p 'test_pack*.py' -v
```

C 测试覆盖原有体感处理，以及四档、CRC 回退、旧版迁移、快捷键与防抖、L2 滞回/ADS、精瞄、保存去重/失败重试、校准超时和统计；另编译三个板型的真实 LED 实现验证提示恢复和优先级。描述符检查 DS / DSE 实际大小 361 / 477 字节，四种体感 Feature 的 data 均为 63 字节。

JS 检查配置、全局快捷动作、导入迁移、足长 HID 包和统计解析。仓库根目录启动 HTTP 服务后，打开 `tests/web_ui_test.html` 运行模拟 WebHID 的表单集成检查；此测试不会访问真实硬件。GitHub Actions 继续执行主机检查和三板型 × FS/HS 六版本编译、打包，下载见 [自动构建说明](CI_CN.md)。

软件测试与编译不能代替真机联调。产物 `build-info.json` 保持 `hardware_validated: false`；网页刷写使用芯片 BootROM 下载模式，不是固件内 OTA；真机验收前仍视为实验功能。
