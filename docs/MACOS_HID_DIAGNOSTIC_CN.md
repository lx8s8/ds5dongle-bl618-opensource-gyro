# macOS 键鼠接口诊断

此分支仅用于当前设备的本地排查，不是发布固件，不合并到正式分支。

当前 Mac 的 `AppleGameControllerPersonality` 按 `054c:0df2` 匹配到了手柄接口和新增键鼠接口，两者均由 `AppleGCHIDUserEventDriver` 接管。G2.1 已恢复鼠标 HID 枚举，但用户在保持网页前台测试时仍未观察到鼠标输出。驱动绑定是待验证的原因，不能仅凭绑定记录判定根因。

本包基于 G2.1，版本为 `LCT616-DS5 3.18G2.1T`。仅把 USB 识别改为 `1209:0001` 和测试名称；手柄蓝牙识别、HID 报告格式、鼠标发送逻辑及体感参数不变。网页只选择此测试身份，Actions 只构建当前使用的 `lctech616-fs`。

`1209:0001` 是 pid.codes 为私下测试保留的 PID，不具有唯一性，不可用于对外分发、出售或制造的设备。不得将本测试身份作为产品身份使用。来源：`pidcodes/pidcodes.github.com` 的 `1209/0001/index.md`。

仅更新主程序并保留本地完整 Flash 备份。运行后检查新身份、通用键鼠驱动绑定和实际鼠标轨迹；测试后可用已校验的 G2.1 主程序恢复索尼身份。测试身份下的原生手柄功能和音频/触觉兼容性不属于本轮验收。
