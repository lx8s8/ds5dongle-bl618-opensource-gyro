# G2 体感扩展协议

对应 `src/gyro.c`、`src/gyro_runtime.c`、`src/dongle_control.c`、`src/diagnostics.c` 和 `web/protocol.mjs`。本文偏移均不含 Report ID，多字节整数为 little-endian。面向用户的操作见 [使用说明](GYRO_CN.md)。

## 报告与执行顺序

| ID | 方向 | data 字节数 | 用途 |
| --- | --- | --- | --- |
| 0xFA | GET | 63 | 四档绑定、当前选择、全局快捷动作 |
| 0xFC | SET / GET | 63 | 命令 / 当前编辑档与回执 |
| 0xFD | GET | 63 | IMU、映射与校准状态 |
| 0xFE | GET | 63 | 接收器处理链路统计 |

DS / DSE HID 描述符为 361 / 477 字节。键盘/鼠标复合接口始终枚举，FS / HS 端点周期均为 1ms。WebHID 的 `sendFeatureReport(id, data)` 只传 data；`receiveFeatureReport(id)` 返回 64 字节，首字节为 ID，网页校验 ID 与足长包。

SET 在 USB ISR 中放入深度 8 的统一队列，由 usb_task 顺序执行，GET 读取双缓冲快照。新客户端每次只发一个命令，等待命令和序号同时匹配的回执后再发下一条。序号建议 1–255 循环；队列满无回执，通过 0xFE 计数和客户端超时诊断。网页超时为 2.5 秒。

## 0xFC SET

data[0] 命令，data[1] 序号，以下未用字节补零至 63。

| 命令 | 参数与行为 |
| --- | --- |
| 1 | data[2..41]：40 字节配置；校验通过后应用到当前编辑档；编辑档正生效时立即更新引擎 |
| 2 | 保存四档与全局设置；不保存零偏，内容相同不重复写 |
| 3 | 开始静止校准 |
| 4 | 当前编辑档恢复默认到 RAM，不自动保存 |
| 5 | 清除手动零偏，保留工厂标定 |
| 6 | data[2]：选择编辑档 0–3，不改变生效档 |
| 7 | data[2]：手动生效档 0–3；全局 source 非 0 时拒绝；约 1 秒后合并持久化档位选择 |
| 8 | data[2..58]：57 字节全局设置，验证后应用到 RAM |

0xFC GET：

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0–39 | bytes | 当前编辑档，编码为配置 v2 |
| 40 / 41 / 42 | u8 各一 | 上一处理命令 / 结果 / 序号；结果 0 成功、1 无效、2 Flash 失败 |
| 43 | u8 | 能力位，G2 为 0xFF |
| 44 / 45 | u8 各一 | 编辑档 / 生效档；档 0–3，生效 255 关闭 |
| 46 / 47 / 48 | u8 各一 | bank 版本 2 / 配置库有未保存更改 / 临时暂停 |
| 49–62 | bytes | 保留为零 |

读取四档可循环发命令 6 并读回 0xFC，最后恢复原编辑档。保存网页全部草稿的顺序：各档选择并应用 → 恢复原编辑档 → 应用全局 → 保存。各条命令是独立应用，过程中某条失败时已成功应用的 RAM 设置仍生效，不声称整个多命令过程具有事务性。

## 40 字节配置 v2

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | u8 | 版本 2；SET 兼容 v1 |
| 1 | u8 | 输出 0 off / 1 mouse / 2 right stick |
| 2 | u8 | 激活 0 always / 1 hold / 2 toggle / 3 hold off |
| 3 / 4 | u8 各一 | 扳机 0 none / 1 L2 / 2 R2；启用阈值 1–255 |
| 5 | u8 | bit0 invertX、bit1 invertY、bit2 suppress、bit3 requireAll |
| 6 / 7 | u8 各一 | 水平轴 0 yaw / 1 roll；平滑 0–100ms |
| 8 | u16 | 长按延时 0–3000ms |
| 10 / 12 | u16 各一 | X / Y 灵敏度 ×100，1–10000 |
| 14 / 16 | u16 各一 | 鼠标 counts/° ×100，1–10000；微动阈值 °/s ×100，0–1000 |
| 18 / 20 / 22 | u16 各一 | 满杆 °/s，1–3000；摇杆死区 ×1000，0–500；曲线指数 ×100，25–400 |
| 24 / 26 / 28 | u16 各一 | 加速倍率 ×100，100–1000；起始 / 结束 °/s，起始 < 结束 ≤ 2000 |
| 30 | u32 | 按键 mask，bit0–23 见下表 |
| 34 | u8 | 摇杆融合 0 add / 1 replace |
| 35 / 36 | u8 各一 | 额外档位限制源 0 不限 / 1 Edge 原生 / 2 remap；允许档位 bitmask |
| 37 | u8 | 释放阈值，1–启用阈值 |
| 38 | u16 | L2 ADS 灵敏度倍率 ×100，1–400 |

v1 的 37–39 必须为零，接收后迁移为“释放阈值=启用阈值、ADS=100”。额外限制源非零时 mask 不得为空，Edge 使用低四位，remap 使用低两位。非 always 激活方式必须有扳机或按键条件。

| bit | 按键 |
| --- | --- |
| 0–3 | □、×、○、△ |
| 4–7 | L1、R1、L2、R2 |
| 8–14 | Create、Options、L3、R3、PS、触摸板按下、Mute |
| 15–18 | ↑、↓、←、→ |
| 19–22 | Edge Fn 左、Fn 右、L4、R4 |
| 23 | 任一触摸接触 |

## 57 字节全局设置

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | u8 | source：0 手动/快捷键，1 Edge 原生 Fn，2 remap 两档 |
| 1 | u8 | 手动档 0–3 |
| 2 | u8 | 板载灯反馈 0 / 1 |
| 3–6 | u8×4 | Edge 原生 △ / □ / × / ○ 分别绑定 0–3 或 255 关闭 |
| 7–8 | u8×2 | remap 档 0 / 1 绑定 0–3 或 255 关闭 |
| 9–56 | 12 bytes×4 | 四个快捷动作 |

每个动作 12 字节：

| 相对偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | u8 | 0 未设置、1 下一档、2 上一档、3 指定档、4 临时暂停开关、5 校准、6 按住精瞄 |
| 1 | u8 | 0 按下、1 长按、2 双击；精瞄不支持双击 |
| 2 / 3 | u8 各一 | 目标档 0–3；屏蔽 0 保留 / 1 组合成立 / 3 始终 |
| 4 | u16 | 长按 ms，0–3000；长按方式必须非零 |
| 6 | u16 | 精瞄倍率 ×100；启用动作时 1–400，精瞄动作最多 100 |
| 8 | u32 | 必须全部按下的 mask；启用动作不得为空，相同 mask 不允许重复 |

未设置动作仍检查枚举、mask 和长按时间的结构有效性；未使用倍率可为 0。按下精瞄为按住即时倍率，长按精瞄在延时后持续生效。

## 0xFA GET

| 偏移 | 数据 |
| --- | --- |
| 0 / 1 / 2 / 3 | 版本 2 / 档数 4 / 编辑档 / 生效档（255=关闭） |
| 4–12 | 全局设置 0–8，其中偏移 5 为当前手动档，包含已切换尚未保存的选择 |
| 13–14 | 保留为零 |
| 15–62 | 全局设置 9–56，四个快捷动作 |

## 0xFD GET

| 偏移 | 数据 |
| --- | --- |
| 0 / 1 / 2 / 3 | 版本 2；flags；引擎输出模式；校准进度 % |
| 4 | u32 样本时间差 µs |
| 8 / 14 | i16×3 原始 gyro / accel |
| 20 / 32 | i32×3 校正角速度 °/s×100；i32×2 滤波映射速度 °/s×100 |
| 40 / 42 | u8×2 处理后右杆（remap 前）；i16×2 待发鼠标整数 counts |
| 46 / 50 | u32 原始按键 mask；u16 校准样本数 |
| 52 / 58 | i16×3 手动零偏 °/s×100；u32 累计样本数 |
| 62 | 低四位：Edge 原生档位 1–4 / 0 未知；bit4–5：remap 档 0 / 1 |

flags：bit0 新鲜输入、bit1 映射激活、bit2 校准中、bit3 有手动校准、bit4 工厂标定、bit5 校准超时。超时可保留此前有效零偏，因此 bit3 与 bit5 可同时为 1。全局关闭时，引擎输出字段仍可能保留上一配置模式，应使用激活位及 0xFA/0xFC/0xFE 的生效档共同判断。

## 0xFE GET

| 偏移 | 类型 | 数据 |
| --- | --- | --- |
| 0 / 1 | u8 各一 | 版本 2 / 生效档（255=关闭） |
| 2 | u32 | 接收器处理输入报告数 |
| 6 / 10 / 14 | u32 各一 | 报告处理间隔 min / max / avg，µs |
| 18 / 22 | u32 各一 | 体感处理耗时 max / last，µs |
| 26 / 30 / 34 | u32 各一 | >50ms 间隔次数 / 鼠标 USB busy / 配置命令队列丢弃 |
| 38 / 39 | u8 各一 | 队列峰值 / 最近保存结果 0 未发生、1 成功、2 失败 |
| 40 / 44 | u32 各一 | Flash 保存耗时 last / max，µs |
| 48–57 | u16×5 | 间隔桶 <2 / 2–<5 / 5–<10 / 10–<20 / ≥20ms |
| 58 | u32 | 实际 Flash 保存尝试次数，去重跳过不计入 |
| 62 | u8 | 保留为零 |

输入间隔取 usb_task 开始处理时钟，含调度/队列/断连影响；不是无线包序号统计。处理耗时覆盖体感 runtime 的主要计算，不含最终快照发布和完整 USB 输出。统计不保存，重启清零；桶 u16 饱和，次数 u32 饱和。

## 旧 0xF6 / 0xF7 / 0xFB

旧 config/remap data 布局保留。SET 也进入统一队列，F7 GET 改为完整 63 字节，前部 `config_body` 不变；偏移 40 命令、41 结果、42 序号、43 来源 Report ID。完整 F6 63 字节的末字节为可选序号；完整 FB 127 字节的末字节为可选序号。旧短包没有序号，回执序号为 0。

F6 命令 1 应用 config，2 保存，3 保存成功后复位。FB 命令 1 设置并保存表（兼容 23/31 项及历史无档号长度）、2 重置并保存、3 选待读档、5 选择生效档。档位必须合法，不再把错误档号静默改成 0。FB GET 为 127 字节，偏移 0 当前档、1 待读档、2–125 为 31 项×4 字节，126 保留。旧表的条目清洗规则沿用原实现。

## Flash 记录

- `gyro_bank_a_v2` / `gyro_bank_b_v2`：229 字节，`GYR2` 4 + generation u32 + 四份40字节配置 + 全局57字节 + CRC32 u32；CRC 覆盖前225字节，交替写入，启动选择代数最新的有效副本。
- `gyro_slot_v2`：9 字节，generation u32 + slot u8 + CRC32 u32；CRC 覆盖前5字节，仅在代数与当前 bank 一致且 slot 有效时采用。
- 旧 `gyro_cfg_v1`：仅用于无有效 G2 bank 时迁移，不再覆盖写入。

这些记录只保存配置，不保存配对密钥、IMU 零偏或当前临时暂停/精瞄状态。
