# G2.4RC3：设备宏与连接稳定性更新

基于上游公开 v3.18，选择性适配 NiceTimeJob/DS5DongleRE R3.28 的代码和设计，来源及 GPL 声明见 NOTICE。本版本不等于合入 sqlCRT v3.24 的全部修复。

- 修复断连命令与回调重入时的连接对象重复释放；保留协商的蓝牙监督超时和现有无输入看门狗。
- Edge 配置预取等待全部 12 项响应，失败或缺失会重试；请求发完不再提前宣布配置齐全。
- 新增设备端宏：16 槽、每宏最多 640 步，支持手柄键、Edge Fn／背键、键盘及修饰键、鼠标按钮和滚轮；单次、指定次数、按住循环、按一下开再按一下关。
- 新增 16 条组合键触发绑定，可设置按下、松开、长按、双击、三击，限定四档体感配置。停止、切档、断连、输入中断时释放宏输出。
- 网页新增“宏与绑定”页：步骤编辑、手柄按键录制、保存回读、JSON／MAC1 导入导出。保存采用校验及临时文件原子替换。
- 现有映射和宏的键鼠状态合并排队，避免互相松键；USB 忙时保留待发状态，不再超时重用仍在传输的 DMA 缓冲。
- 保存最近一次手动静止校准，仅在手柄标识及工厂标定匹配时恢复；现有四档速度、反转、曲线和配置协议继续保留。
- 导出诊断增加物理输入／输出对照和连接事件，辅助排查 Windows 输入失效。
- 保留 Sony 054C:0CE6／054C:0DF2 及 Edge 名称。普通应用不含双固件安装；完整烧录包仍含标准 Boot2 与分区表，双固件设备不得直接整包刷写。实验原型额外隔离 media 文件区，尚未完成真机启动验证。

Windows x64、Mac Apple Silicon、Mac Intel 请选择对应 DS5-Control-Center 应用 ZIP，无需安装 Python；source.zip 供源码运行。固件请选择匹配板型的 FS／HS ZIP，包内附来源及哈希。

本版本为预发布。主机测试、模拟网页和编译检查不代替真机：新增宏及键鼠合并需实际验收，Apex 双摇杆失效尚未复现确认，不能宣称已经解决；Mac 键鼠接口仍需兼容性验证。上游原版配置库和本项目宏文件使用不同协议，不可混用整套配置。

升级需刷入新主程序，只更新网页不能获得设备宏；先导出配置，按包内步骤操作。刷入前后的普通配置应保留，首次不要安装实验双固件管理器。操作说明见 docs/CONTROL_CENTER_CN.md。
