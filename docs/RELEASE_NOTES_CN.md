# G2.4RC6：重力融合玩家空间、自动温漂校正、右摇杆向导、命名配置库与离线回放

基于上游公开 v3.18，选择性适配 NiceTimeJob/DS5DongleRE R3.28 的代码和设计，来源及 GPL 声明见 NOTICE。本版本不等于合入 sqlCRT v3.24 的全部修复。

- **重力融合 `Player Space` 玩家空间坐标系**：水平转向轴新增 `玩家空间 · 重力防串轴`（`GYRO_AXIS_PLAYER_SPACE = 2`）及快捷预设，结合三轴加速度计实时估计重力方向，消除斜握俯仰与水平转向串轴。
- **自动静止检测与温漂零偏慢速学习**：新增 `GYRO_AUTO_BIAS`（1 秒静止窗口检测 + 慢速指数跟踪温漂零偏，绝不把慢速跟枪误学为零偏），并在测试页实时显示 `静止锁定 / 静止 · 自动跟踪 / 运动中` 状态。
- **自适应速度分段微瞄滤波**：新增 `GYRO_ADAPTIVE_SMOOTH`，小幅微瞄（`1.8x` 时间常数）强力抑制生理手抖，大幅甩枪（`>= 45 °/s`）自动旁路滤波实现零延迟直通。
- **右摇杆视角校准向导与游戏模板**：内置 Apex 经典/线性、使命召唤 CoD 动态、守望先锋 2、战地通用 5 套模板，并提供按游戏死区 `%`、满杆转 360° 用时 `s`、响应曲线一键反推最佳满杆转速、死区补偿与指数的三步计算器。
- **配置档备注命名、本地配置方案库、一步撤销与导入差异预览**：支持 4 档自定义备注名、浏览器本地多方案保存与单档/整套载入、一步撤销回退，以及导入 JSON 时的逐档变更对比预览面板；附带原生体感 / Steam / 固件映射双重叠加兼容检查向导。
- **手柄测试增强、诊断离线回放与便捷软重启**：新增顶部实时轮询率徽标与标准差抖动统计、左右摇杆 36 扇区实时圆度 RMS 误差百分比、诊断 JSON 离线逐帧回放（无需连接硬件复盘陀螺仪曲线与按键）、接收器 `0xF6/5` 仅软重启按钮及 `750 Hz (实时)` 频率标签修复；修复 macOS 原生启动器非阻塞套接字继承导致的偶发静态资源加载中断。
- **延续 G2.4RC5 网页直刷、更新检测、双固件维护与 16 槽设备宏**：保留 Web Serial ISP 直刷、在线版本检查与一键下载、双固件 4 MiB 备份/安装/分槽更新/恢复，以及 16 槽 × 640 步设备端宏。

Windows x64、Mac Apple Silicon、Mac Intel 请选择对应 DS5-Control-Center 应用 ZIP，无需安装 Python；source.zip 供源码运行。固件请选择匹配板型的 FS／HS ZIP，包内附来源及哈希。

本版本为预发布。主机测试、模拟网页和编译检查不代替真机：Web Serial 烧录与双固件槽位操作前建议先执行“备份 4 MiB 镜像”并导出配置；操作说明见 docs/CONTROL_CENTER_CN.md 与 docs/DUAL_FIRMWARE_CN.md。
