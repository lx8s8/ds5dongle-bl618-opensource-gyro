刷写指南 · 3 步完成

  1. 下载并选中固件包
    在上方版本列表一键下载匹配板型与 USB 速度的固件 ZIP，无需手动解压。
  2. 核对板型与写入模式
    加载包后核对目标板型与模式并勾选确认；常规升级选“仅主固件”可保留设置。
  3. 按住 BOOT 插入 USB 刷写
    按住接收器上的 BOOT 键 插入电脑 USB 后松开，点击 开始刷写 并选择串口；完成后会 自动重启。
