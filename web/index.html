03 / FIRMWARE

构建与烧录

当前固件：未连接

此分支通过串口 / ISP 烧录更新。网页提供配置和测试；当前固件没有 OTA 写入协议。

  1. 按仓库 README_CN.md 安装专用 Bouffalo SDK 分支和 T-Head 工具链。
  2. 在仓库执行 bash build_macos.sh build，默认构建 LCTech BL616。
  3. 按住开发板 BOOT 接入，使用 Dev Cube 的 BL616 UART / ISP 模式。
  4. 选择 partition_cfg_4M_nosec.toml、Boot2 和对应开发板的固件，完成烧录后重新配对。

网页连接 USB 接收器；直接连接原装手柄或旧固件时会提示缺少 0xFC / 0xFD 协议。当前仅接入 DualSense / DualSense Edge，其他品牌需先实现其蓝牙协议。
